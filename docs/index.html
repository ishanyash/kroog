The map of your Claude Code chats.

One local page that shows every Claude Code chat you have in VS Code, Cursor or the terminal: what each one did, which ones are waiting on you, and how they came from each other. Pick a few and start the next chat with what they worked out.

install source on GitHub Free and open source (MIT). Runs only on your computer.

see

Every chat, as a week

A band per project, a box per chat on the day it started, and lines where one chat came from another. Four states at a glance: working, needs you, open in your editor, done.

The pixels behind the week are live. Every step a working chat takes drops a short run of cells under its box.

understand

A short read per chat

Click a chat for what has been done (up to three lines) and what is left (up to two). The plan, the files, the agents and the full conversation are one click further, under "more".

connect

The next chat starts where the last ones ended

  1. Pick two or three chats, or take a group Kroog suggests.
  2. Add a goal, and press the button.
  3. VS Code opens a new chat, and its first message is what those chats worked out.
  4. The chat reads it, replies in a few lines, and waits for you.

No re-explaining, and nothing runs until you ask.

burn

Your plan's limits, and where the usage went

The 5-hour and weekly windows at the top of every page, with a mark where an even pace would be. A page with when the week runs out at this pace, and the last seven days by day, project, model and chat.

The numbers are Claude Code's own: each chat's cost record and its plan windows, through a small open-source plugin.

Install

Try it first, with made-up chats. Nothing is changed.

npx github:ishanyash/kroog demo

Then install it for real. link backs up ~/.claude/settings.json before it adds its hooks.

git clone https://github.com/ishanyash/kroog.git ~/kroog
cd ~/kroog
node bin/kroog.js link
node bin/kroog.js start

Yours, and only on your computer

Local only

Kroog listens on 127.0.0.1. Other computers cannot reach it, and other websites cannot call it. No accounts, no telemetry, no analytics.

Never in charge

Kroog never runs a chat and never edits your code. Its messages arrive as messages from another session, which Claude Code never takes as your approval.

Checked, not promised

The repository lists exactly what Kroog reads, writes and connects to, and a test fails the build if the code steps outside it. It never reads your credentials.

Questions

Is Kroog made by Anthropic?

No. It is an independent open-source tool built on Claude Code's public features: hooks, its registry of open chats, chat inboxes and the plugin API.

What does it cost?

Kroog is free. The short summaries are written by a small model, by default Claude Code with Haiku on your plan, with a daily cap. You can use a local model with Ollama, your own API key, or turn it off.

Why are the dollars on the burn page so high?

They are what the tokens would cost on the API at list price, the same figure Claude Code reports. On a Pro or Max plan you pay the plan's price, not this. Most tokens are cache reads, because every request re-reads the conversation so far.

Does it work with Cursor or the terminal?

Chats from VS Code, Cursor and the terminal all show up. Opening a chat or starting a new one from Kroog is built and tested for VS Code.

Will it keep working when Claude Code updates?

Some of what Kroog reads is internal to Claude Code and can change. When something changes, Kroog falls back (for example, to putting the context on your clipboard) and says so.
